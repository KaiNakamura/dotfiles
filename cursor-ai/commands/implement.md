# Implementation Phase

Your task is to **execute the implementation plan** by writing the necessary code changes.

## Prerequisites

- Read `.thoughts/plan.md` to understand the implementation plan
- If no plan exists, you may need to create one first using `/plan`

## Execution Guidelines

**Follow the plan precisely:**
- Make changes to the specified files
- Implement the provided code snippets exactly as planned
- Do not deviate from the plan without explicit approval

## Progress Tracking

For each completed step, **update `.thoughts/plan.md`** with:

- **Completion Timestamp**: When the step was finished
- **Files Modified**: Exact paths and line ranges changed
- **Tests Added/Updated**: Specific test cases implemented
- **Verification Results**: Pass/fail status of validation steps
- **Context Usage**: Current percentage of context window used (if known)
- **Next Step Prep**: Any setup needed for the following task

## Context Management

- **Continuously monitor your context utilization**
- If you approach 40% of the context window, compact your progress by updating `.thoughts/plan.md` with current status
- Focus on the next distinct phase described in the plan
- Archive detailed logs to separate files if needed

## Testing Requirements

- Generate all specified unit tests to verify functionality
- Run tests and document results in the plan updates
- Ensure all test cases from the plan are implemented

## Error Handling

- **Do not deviate from the plan** without explicit approval
- If you encounter unexpected issues or need clarifications:
  - Halt the implementation
  - Report the problem clearly
  - Update the plan with the blocker
  - Await further instructions

## Success Criteria

- All planned changes are implemented
- Tests are written and passing
- Plan document is updated with progress
- Code follows existing patterns and conventions
- No unintended side effects introduced
