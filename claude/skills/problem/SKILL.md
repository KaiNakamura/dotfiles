Create or update the problem definition for the current project.

The problem statement is user-controlled, use their exact words, do not embellish. Do not tighten it, summarize it, or improve it. If what they gave you is long and messy, the long messy version is the artifact: their phrasing carries intent a cleaned-up version loses, and this is the one thing in a project that stays authoritative while everything around it changes.

Use this to revise an existing statement too, as understanding of the problem sharpens. Revising is still the user's words replacing the user's words.

Creating the project itself is `/new-project`.
