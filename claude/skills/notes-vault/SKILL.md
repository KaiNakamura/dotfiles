---
name: notes-vault
description: When a task needs context from the user's personal notes vault (daily notes, people, hobbies, habits, projects, etc.)
---

The notes vault is personal and sensitive. Read with care.

- Pull in changes before reading
- Read `AGENTS.md` at the vault root for where things live
- Stay on task. Don't browse unrelated areas
- Cite the notes you used when appropriate
- Don't quote notes in public places or other repos, and don't bulk copy them, opt for summarizing instead
- Agents typically write to the thoughts vault, not the notes vault
- The notes vault can be edited only via PRs
