---
name: checkpoint
description: Save a progress summary capturing the current state for handoff to the next session
---

Write down enough that a cleared agent picks up without re-deriving anything.

Cover what has been decided, what is in flight, what is blocked, and what to do next. Include the reasoning behind the decisions, not just the decisions: without the why, the next agent relitigates settled ground, and rejected options come back.

Preserve anything the user said in their own words. Their wording is the first thing a summary destroys and the last thing that should go.

Be precise and brief. This gets read cold by something with no memory of the conversation, so every sentence has to survive without the surrounding context.
