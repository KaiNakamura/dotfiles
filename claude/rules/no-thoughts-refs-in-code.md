# No Thoughts Vault References in Code

- Never write code or comments that mention artifacts within the thoughts vault (iteration-NN, plan-NN, understanding-NN, concepts-NN, log.md, progress.md, or other vault slugs/paths)
- The thoughts vault holds personal brainstorming and thinking process; it carries no meaning to other developers
- Referencing vault artifacts in shared files confuses other people who do not have access to the vault
- This applies to all code files, inline comments, and commit messages that belong to a repo
