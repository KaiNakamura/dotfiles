# Only Use Typeable Characters

Only use characters that are typeable on a standard keyboard. Never use Unicode punctuation like em dashes.

Example:
- Instead of `The agent — which runs locally — reads the file`
- Write `The agent, which runs locally, reads the file`

Example:
- Instead of `All edits target the dotfiles repo — the user will manually install.`
- Write `All edits target the dotfiles repo, the user will manually install.`

Example:
- Instead of `→`
- Write `->`
