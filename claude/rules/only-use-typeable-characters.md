# Only Use Typeable Characters

Only use characters that are typeable on a standard keyboard. Never use Unicode punctuation like em dashes.
For em dashes specifically, never replace with `--`. Choose an appropriate alternative based on the context.

Example:
- Instead of `The agent — which runs locally — reads the file`
- Write `The agent, which runs locally, reads the file`

Example:
- Instead of `Edits target the dotfiles repo — the user will manually install.`
- Write `Edits target the dotfiles repo, the user will manually install.`

Example:
- Instead of `Concept A — Create custom Dockerfile`
- Write `Concept A: Create custom Dockerfile`

Example:
- Instead of `→`
- Write `->`
